# Security

Report suspected vulnerabilities privately through the GitHub
[DarkWingMcQuack/pspsps](https://github.com/DarkWingMcQuack/pspsps)
repository's **Security → Report a vulnerability** form when private reporting
is enabled. If it is unavailable, contact the repository owner privately before
sharing sensitive reproduction details. The project has no public reporting
address configured yet; maintainers must enable and document a private reporting
channel before the first public release.

Include the affected version, Scala and platform versions, a minimal
reproduction, and the expected impact. Do not post credentials, customer data,
or exploitable infrastructure details in a public issue.

Resource lifecycle and cancellation behavior follow Cats Effect and FS2.
Dependency upgrades and changes to syntax that manages resources still require
regression checks. This project is currently unreleased; a version support
policy will accompany the first release.
