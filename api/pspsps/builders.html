sealed trait Branch[F[_], Input, A]

Internal-to-the-DSL interpretation of a branch argument.

Internal-to-the-DSL interpretation of a branch argument.

Automatic syntax unwraps exactly one F layer. The plain-value instance is unavailable for an F-shaped input. Use withLeftPure / withRightPure / withSomePure when the effect itself is intentionally the payload.

Input is invariant: this prevents an effect from being widened to Any and silently selected as a pure value. Widen effect subclasses to F[A], or use the explicit ...F methods (which supply that expected type).
